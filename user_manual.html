1. wmrSim 可以做什麼

wmrSim 是 ROS 2 Jazzy 上的多機器人模擬與車隊操作軟體。桌面視覺化工具用於 3D 場域、機器人與感測資料檢視；Web Dashboard 用於營運總覽、地圖任務派送、車隊狀態與事件監控。兩個介面連接同一個模擬與 Gateway。

功能用途主要介面
多車隊模擬檢視機器人位置、狀態、路徑與任務執行情況。桌面 GUI、Dashboard
地圖與樓層載入地圖、切換樓層，管理樓層和地圖的對應。桌面 GUI、Dashboard
導航任務在地圖選取機器人、加入目標點、選擇 P2P、DWA 或 TEB，然後派送任務。Dashboard 地圖調度、桌面 GUI
感測顯示查看地圖、LiDAR、Point Cloud 與可用的相機資訊。桌面 GUI、Dashboard 總覽
交通與電梯觀察交通資源／保留狀態、樓宇設施及電梯協調狀態。Dashboard、桌面電梯面板
任務與診斷查看任務事件、車隊指標、Gateway 連線及服務能力。Dashboard
Dashboard 的命令與資料頁面會依 Gateway 是否提供相應 API、目前使用者權限及後端服務狀態而顯示。若某項能力不可用，請先查看「系統設定」中的連線與能力資訊。

2. 啟動與連線

Ubuntu 24.04 安裝完成後，以一般登入帳號開啟 Terminal：

wmrsim doctor
wmrsim start

wmrsim doctor 檢查 ROS 2、核心套件、Dashboard 與 SDK；wmrsim start 啟動模擬、Gateway 和桌面 GUI，並嘗試開啟瀏覽器。Dashboard 預設網址是 http://127.0.0.1:8080/。

沒有桌面環境的主機使用 wmrsim start --headless，之後從有權限的瀏覽器連到該主機所設定的 Gateway 位址。不要以 sudo wmrsim start 啟動 GUI。

若 Gateway 啟用登入，使用管理者提供的帳號登入。Dashboard 顯示「Offline」或連線錯誤時，先確認模擬與 Gateway 已啟動，再到「系統設定」檢查 Gateway URL、連線狀態及 API 能力。

3. 桌面 3D GUI

主視窗由上方工具列、左側設定面板、中央 2D/3D 場域視圖和下方狀態列組成。左側的「WMR 管理」、「場域管理」、「顯示圖層」可分別展開或收合。

3.1 機器人與原點

  1. 在「WMR 管理」選取機器人，查看或設定 X、Y、Theta（弧度）、所在樓層及導航演算法。
  2. 按「更改原點／樓層」套用選取機器人的起始位置或樓層。
  3. 按「開始移動任務」開始目前選定的移動任務。新增或退役機器人屬維護操作，操作前確認車隊設定及目標樓層。
  4. 「復原已退役 WMR」可從封存清單還原曾退役的機器人；如封存的樓層或地圖與目前設定不相容，系統會拒絕還原。

3.2 地圖、樓層與任務點

「場域管理」含「地圖」、「樓層」、「電梯」頁籤。於地圖頁載入清單中的地圖，或加入外部地圖 YAML；於樓層頁新增、儲存、刪除樓層並指定地圖與樓高，再按「顯示此樓層」。刪除樓層前確認沒有機器人或電梯設定依賴該樓層。

工具列開啟「設定目標點」後，在地圖上依序點選位置。可選點位種類；停靠點可設定停靠秒數，資源 ID 可留空或填入對應資源。按「清除目標點」清除目前編輯的路徑；按「匯出目標 JSON」保存目標點。場域中的已儲存任務點可在左側「任務點位管理」儲存或清除。

3.3 感測圖層與電梯

展開「顯示圖層」可切換 Map、LiDAR Scans、Point Cloud，並調整 LiDAR 障礙點大小。「檢視」選單可開啟視覺感測控制面板；其中障礙物輔助和 Tag 定位選項是否可用，取決於目前場景與感測資料。

「場域管理 → 電梯」顯示電梯、樓層、運行／門狀態、使用者、排隊與故障資訊。人工呼叫及模擬到站等維護控制只在系統允許的維護狀態下使用；先確認電梯及機器人狀態再送出命令。

3.4 3D 視角操作

操作功能
2D 俯視按工具列「2D [1]」或鍵盤 1
3D 環繞按「3D [3]」或鍵盤 3
重設視角／顯示完整地圖檢視選單「重設視角」／「顯示完整地圖」；快捷鍵 Z／Home
聚焦／跟隨選定車輛檢視選單「聚焦選定 WMR」（F）或開啟「跟隨選定 WMR」
平移／縮放2D：左鍵拖曳平移、滾輪縮放；3D：中鍵平移、右鍵上下縮放
旋轉2D：右鍵或 Shift+拖曳；3D：左鍵拖曳環繞

點選目標點時左鍵用於放置；中鍵或 Space+左鍵可平移，滾輪縮放。視窗「說明 → 視角操作說明」也會顯示操作提示。

4. Web Dashboard

Dashboard 左側導覽切換營運頁面；頂端顯示當前頁面與 Gateway 連線狀態。小螢幕會改用行動版導覽；地圖頁提供適合手持裝置的全螢幕地圖操作。

4.1 從地圖派送導航任務

  1. 開啟「地圖調度」，先選擇樓層，再選擇要派送任務的機器人。
  2. 選擇導航模式：P2P、DWA 或 TEB。
  3. 在地圖上點選路徑目標點，檢查目標點順序和地圖位置。需要重來時按「清除目標點」。
  4. 確認所選機器人、樓層與路徑後按「派送任務」。命令能力或帳號權限不足時，按鈕會停用或顯示錯誤。
  5. 到「任務中心」查看任務狀態及事件；到「機器人」查看車輛連線與位置。
派送前請確認目標點位於正確樓層與可通行區域。模擬環境畫面上的路徑不代表真實設備已完成動作。

5. Dashboard 頁面說明

頁面畫面用途操作提示
營運總覽車隊在線數、執行中任務、作用樓層、需注意事件；即時地圖、活動、相機影像及車隊快照。由總覽卡片或地圖連結進入相關頁面。
地圖調度樓層與機器人選擇、路徑編輯及導航派送。先選樓層與車輛，再編輯目標點及派送。
機器人車隊清單、單機狀態／位置／連線品質及地圖。用來確認派送對象和執行中的車輛狀態。
任務中心活動任務與任務事件清單。追蹤事件時間、任務、車輛、狀態及來源；此頁主要用於監看。
交通管理交通演算法可用狀態、任務、資源、保留資訊、錯誤及交通事件。若顯示無狀態，檢查 Gateway 是否提供 Traffic API。
Metrics機器人總數、在線數、執行／完成任務及車隊、任務、交通事件趨勢。Gateway 啟動後逐步累積樣本；新啟動時暫時沒有圖表屬正常。
樓宇設施電梯、電動門、閘門、輸送帶等設施狀態與控制項。命令由 Gateway 傳送並由後端授權；只操作已配置且允許的設施。
貨物條碼貨物清單、條碼掃描事件及交貨狀態。資料由 Gateway 與後端協調服務提供。
電梯監控電梯協調器啟用時才出現，顯示樓層、移動狀態與電梯台數。若未出現，代表目前未偵測到啟用中的電梯協調器。
系統設定資料來源模式、連線／就緒狀態、即時通道、Gateway URL 與 API 能力。Gateway URL 有變更時使用頁面的連線測試與連線提示。

若伺服器要求登入，Gateway 登入頁會依部署設定提供帳號驗證；系統管理員負責建立帳號與設定可用角色。

6. 狀態與問題排除

現象建議處理
Dashboard 顯示 Offline確認 wmrsim start 的終端仍在執行；開啟「系統設定」檢查 Gateway URL、連線測試、ready 狀態和資料來源。
地圖或車輛列表空白確認場景已載入、所選樓層有地圖且 ROS 節點已啟動；桌面端先在「場域管理」載入地圖。
派送任務按鈕停用確認已選樓層、機器人與至少一個目標點；也要確認 Gateway 命令 API 與目前帳號權限可用。
交通／電梯／貨物頁沒有資料這些頁面依賴對應的後端服務和 Gateway API；查看頁面空狀態及系統設定的能力清單。
模擬啟動失敗執行 wmrsim doctor，保留啟動終端的完整錯誤訊息，再依錯誤修復 ROS 或套件環境。

停止模擬時回到啟動它的終端按 Ctrl+C。日常使用請從桌面應用程式或一般帳號終端啟動，不需要重新安裝或手動載入 ROS 環境。
